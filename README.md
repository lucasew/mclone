# mclone

Rclone, but for model providers.

Config example: https://gist.github.com/lucasew/b2ae17dfcfc87315a853caa08567a37c

You can reuse the same mental model from Rclone in this project.

- Remotes -> Providers
- Files/Folders -> Models

Run `mclone --help` for more details on usage

It works everywhere Go works, including Termux.

This is considered experimental, even though I got Gemini working on Claude Code.
